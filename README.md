## 🎯 What Is This?

**evidence-based-copywriting** is a smart assistant that helps you write marketing copy where every single claim you make is traceable to a real source. Think of it as a fact-checker that works alongside you while you write.

Instead of guessing or hoping your statements are accurate, this tool fetches supporting evidence, labels each claim, and runs a rigorous verification process before you publish anything. It's like having a compliance officer, a researcher, and a sharp editor all in one package.

Whether you're writing a landing page, a product description, or a full marketing campaign, this tool ensures your words are not only persuasive but also defensible and substantiated.

## 🛠️ How to Use It

### Step 1: Write Your Copy
Type your marketing copy as you normally would. Don't worry about claims yet — just get your ideas down.

### Step 2: Review the Claims Panel
On the right side of the screen, you'll see every claim your text makes. Each one is listed with a status:
- **Unverified** (red) — no source attached yet
- **Fetching** (yellow) — the tool is searching for a source
- **Verified** (green) — a source is attached and confirmed

### Step 3: Attach Sources
For each unverified claim, click the **"Find Source"** button. The tool will search the web and suggest relevant pages. Pick the best match, and it will be attached automatically.

### Step 4: Run Verification
Once all claims have sources, click **"Verify All"** in the top toolbar. This runs the adversarial check. Any issues will be highlighted with specific feedback on how to fix them.

### Step 5: Export and Publish
When everything passes, click **"Export"** to save your polished, verified copy. You can export as a plain text file, an HTML file, or a Markdown document — whatever you need for your next step.

## 🧩 Troubleshooting

### The download seems stuck
Try pausing and resuming, or right-click the link and select "Save Link As..." to download to a different location.

### The application won't open
Make sure you've extracted the ZIP file completely before trying to run it. If Windows shows a SmartScreen prompt, click "More Info" and then "Run Anyway" — this is normal for downloaded files.

### Claims aren't fetching sources
Check your internet connection. Also verify that the tool has permission to access the web through your firewall. Look for a firewall popup that needs approval.

### The verification says "failed" but I don't know why
Click the "Details" link next to the failed claim. It will show you exactly which part of the claim couldn't be verified and give you a suggestion for fixing it.
